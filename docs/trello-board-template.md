# Trello - Template de quadro

## Listas
- Fase 0 - Preparacao
- Fase 1 - Base do app
- Fase 2 - Mensalidades
- Backlog
- Refinamento
- A Fazer (Sprint)
- Em Progresso
- Code Review
- Testes
- Concluido

## Cartoes iniciais por fase

### Fase 0 - Preparacao
- [Infra] Instalar Flutter, Android Studio, JDK e PostgreSQL
- [DevOps] Criar repositorio no GitHub (app e API)
- [Gestao] Criar quadro do projeto no Trello
- [Infra] Criar banco no Supabase, Neon ou Render
- [Arquitetura] Desenhar modelo de dados
- [UX] Rascunhar telas principais no papel

### Fase 1 - Base do app
- [Backend] Criar projeto Spring Boot conectado ao PostgreSQL
- [Backend] Implementar login com e-mail/senha e JWT
- [Backend] Implementar perfis de acesso (diretoria/membro)
- [Backend] CRUD de membros
- [Backend] Cadastro de motos ligado ao membro
- [Mobile] Tela de login
- [Mobile] Lista de membros com busca
- [Mobile] Detalhes do membro com motos
- [Mobile] Formularios de cadastro e edicao

### Fase 2 - Mensalidades
- [Backend] Gerar mensalidades por membro e por mes
- [Backend] Marcar mensalidade como pago/pendente
- [Backend] Consultar historico e inadimplentes
- [Mobile] Tela de mensalidades do mes
- [Mobile] Lista de inadimplentes
- [Mobile] Historico de pagamentos por membro

## Definicao de pronto (DoD)
- Codigo revisado por pelo menos 1 pessoa
- Testes basicos executados
- Sem erros de lint
- Documentacao minima atualizada
- Card movido para Concluido
